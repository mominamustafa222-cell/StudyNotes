Chapter 1: Arrays

1.1 Definition

Array is a collection of elements of same data type stored at contiguous memory locations.

Declaration: int arr[5]; // Array of 5 integers
Index: 0 to n-1 where n = size of array
Access Time: O(1) - Constant time

1.2 Array Operations

1. Traversal: Visit each element - O(n)

2. Insertion: O(n) - worst case at beginning

3. Deletion: O(n) - shifting required

4. Searching: Linear O(n), Binary O(log n) if sorted

int arr[5] = {10, 20, 30, 40, 50};
// Traversal
for(int i=0; i<5; i++){
  printf("%d ", arr[i]);
}

Chapter 2: Linked List

2.1 Definition

Linked List is a linear data structure where elements are not stored at contiguous locations. Each element contains data and pointer to next node.

Node Structure:
struct Node {
  int data;
  struct Node* next;
};

2.2 Types of Linked List

1. Singly Linked List: Each node points to next node only

2. Doubly Linked List: Each node has prev and next pointer

3. Circular Linked List: Last node points to first node

2.3 Operations on Linked List

1. Insertion at Beginning: O(1)

void insertFirst(int data){
  struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
  newNode->data = data;
  newNode->next = head;
  head = newNode;
}

2. Deletion: O(n) to find node, O(1) to delete

3. Traversal: O(n)

4. Searching: O(n) - Linear search only

Chapter 3: Array vs Linked List

Array: Fixed size, Fast access O(1), Slow insert/delete O(n)
Linked List: Dynamic size, Slow access O(n), Fast insert/delete O(1) at head

Chapter 4: Stack & Queue Basics

4.1 Stack - LIFO

Push: Insert at top, Pop: Remove from top

Applications: Function calls, Undo operation, Expression evaluation

4.2 Queue - FIFO

Enqueue: Insert at rear, Dequeue: Remove from front

Applications: CPU scheduling, Print queue, BFS
