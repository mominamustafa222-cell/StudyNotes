Chapter 1: Limits & Continuity

1.1 Definition of Limit

If f(x) approaches L as x approaches a, then limx→a f(x) = L

Important Limits:
1. limx→0 (sin x)/x = 1
2. limx→0 (1-cos x)/x = 0
3. limx→∞ (1+1/x)x = e

1.2 Continuity

A function f(x) is continuous at x = a if:

1. f(a) is defined 2. limx→a f(x) exists 3. limx→a f(x) = f(a)

Chapter 2: Differentiation

2.1 Basic Rules

1. Power Rule: d/dx(xn) = nxn-1
2. Product Rule: d/dx(uv) = u'v + uv'
3. Quotient Rule: d/dx(u/v) = (u'v - uv')/v²
4. Chain Rule: d/dx f(g(x)) = f'(g(x)) × g'(x)
Example: Find d/dx(x³ + 2x² + 5)
Solution: 3x² + 4x + 0 = 3x² + 4x

2.2 Standard Derivatives

1. d/dx(sin x) = cos x

2. d/dx(cos x) = -sin x

3. d/dx(tan x) = sec²x

4. d/dx(ex) = ex

5. d/dx(ln x) = 1/x

Chapter 3: Applications of Derivatives

3.1 Maxima & Minima

First Derivative Test: If f'(x) = 0 and f''(x) < 0 → Maxima, f''(x) > 0 → Minima

Example: Find maxima/minima of f(x) = x³ - 3x² + 2
Solution: f'(x) = 3x² - 6x = 0 → x = 0, 2
f''(x) = 6x - 6
At x=0: f''(0) = -6 < 0 → Maxima at x=0
At x=2: f''(2) = 6 > 0 → Minima at x=2

3.2 Tangents & Normals

Tangent: y - y₁ = m(x - x₁) where m = f'(x₁)
Normal: y - y₁ = (-1/m)(x - x₁)

Chapter 4: Integration Basics

4.1 Standard Integrals

1. ∫xndx = xn+1/(n+1) + C, n ≠ -1

2. ∫1/x dx = ln|x| + C

3. ∫exdx = ex + C

4. ∫sin x dx = -cos x + C

5. ∫cos x dx = sin x + C

4.2 Integration by Parts

Formula: ∫u dv = uv - ∫v du
ILATE Rule: I-Inverse, L-Log, A-Algebraic, T-Trig, E-Exponential
