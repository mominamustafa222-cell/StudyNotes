Chapter 1: Introduction to HTML5

1.1 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages. HTML describes the structure of a web page using elements/tags.

HTML5: Latest version of HTML. Released in 2014. Supports multimedia, new semantic elements, better form controls, and APIs.

1.2 Basic Structure of HTML5 Document

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
</head>
<body>
  <h1>This is a Heading</h1>
  <p>This is a paragraph.</p>
</body>
</html>

Explanation:

1. <!DOCTYPE html> - Defines document type as HTML5

2. <html> - Root element of HTML page

3. <head> - Contains meta information about the document

4. <title> - Specifies title for the page shown in browser tab

5. <body> - Contains visible page content

Chapter 2: HTML5 Text Elements

2.1 Headings

HTML has 6 heading levels from <h1> to <h6>. <h1> is most important, <h6> is least.

Example:
<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Sub Sub Heading</h3>

2.2 Paragraphs and Line Breaks

<p> tag defines a paragraph. Browsers add margin before and after each paragraph.

<br> tag inserts a single line break. It is an empty tag with no closing tag.

<p>This is first paragraph.</p>
<p>This is second <br> paragraph with line break.</p>

2.3 Text Formatting Tags

1. <b> and <strong>: Bold text. <strong> has semantic importance.

2. <i> and <em>: Italic text. <em> means emphasized.

3. <u>: Underlined text

4. <mark>: Highlighted text

5. <small>: Smaller text

6. <del>: Deleted text with strikethrough

7. <ins>: Inserted text with underline

8. <sub>: Subscript text - H2O

9. <sup>: Superscript text - X2

Example:
<p>This is <b>bold</b>, <i>italic</i>, and <mark>highlighted</mark> text.</p>
<p>Water formula: H<sub>2</sub>O</p>
<p>Equation: X<sup>2</sup> + Y<sup>2</sup></p>

Chapter 3: HTML5 Lists

3.1 Unordered List

Uses <ul> tag. List items marked with bullets. Each item uses <li> tag.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

3.2 Ordered List

Uses <ol> tag. List items marked with numbers or letters.

<ol type="1">
  <li>Install Editor</li>
  <li>Write Code</li>
  <li>Run in Browser</li>
</ol>

Type attribute: 1, A, a, I, i for different numbering styles.

3.3 Description List

Uses <dl> with <dt> for term and <dd> for description.

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

Chapter 4: HTML5 Links and Images

4.1 Anchor Tag - Hyperlinks

<a> tag creates hyperlink to another page or section.

Syntax: <a href="URL">Link Text</a>
Example 1: External Link
<a href="https://www.google.com">Visit Google</a>

Example 2: Open in new tab
<a href="https://www.google.com" target="_blank">Google</a>

Example 3: Link to section on same page
<a href="#section1">Go to Section 1</a>

Target attribute values: _blank, _self, _parent, _top

4.2 Image Tag

<img> tag embeds an image. It is empty tag with no closing.

Syntax: <img src="image.jpg" alt="Description" width="300" height="200">

Attributes:

1. src - Path to image - Required

2. alt - Alternative text if image not loaded - Required for accessibility

3. width and height - Image dimensions in pixels

4. title - Tooltip text on hover

Example:
<img src="logo.png" alt="Company Logo" width="200" height="100">

Chapter 5: HTML5 Tables

5.1 Basic Table Structure

Tables use <table>, <tr> for rows, <th> for headers, <td> for data cells.

<table border="1">
  <tr>
  <th>Name</th>
  <th>Age</th>
  </tr>
  <tr>
  <td>Ali</td>
  <td>20</td>
  </tr>
</table>

5.2 Table Attributes

1. colspan: Merge cells horizontally

2. rowspan: Merge cells vertically

3. border: Table border width

4. cellpadding: Space between cell content and border

5. cellspacing: Space between cells

Example with colspan:
<td colspan="2">Merged Cell</td>

5.3 Semantic Table Tags

<thead> - Table header group

<tbody> - Table body group

<tfoot> - Table footer group

<caption> - Table title/caption

Chapter 6: HTML5 Forms

6.1 Form Tag

<form> tag creates HTML form for user input.

Attributes:
action - URL where form data is sent
method - GET or POST
name - Form name

6.2 Input Types in HTML5

1. text: Single line text input

2. password: Password field with masked characters

3. email: Email address with validation

4. number: Numeric input with spinner

5. date: Date picker

6. radio: Radio button for single selection

7. checkbox: Checkbox for multiple selection

8. submit: Submit button

9. reset: Reset button

10. file: File upload

<form action="/submit" method="post">
  <label>Name:</label>
  <input type="text" name="name" required><br><br>
  <label>Email:</label>
  <input type="email" name="email" required><br><br>
  <label>Password:</label>
  <input type="password" name="pass"><br><br>
  <input type="submit" value="Register">
</form>

6.3 Other Form Elements

1. <textarea>: Multi-line text input

2. <select>: Dropdown list with <option> tags

3. <button>: Clickable button

4. <label>: Label for input element

Select Example:
<select name="country">
  <option value="pk">Pakistan</option>
  <option value="in">India</option>
</select>

6.4 Form Validation Attributes

1. required: Field must be filled

2. placeholder: Hint text

3. maxlength: Maximum characters

4. pattern: Regular expression for validation

5. min/max: For number and date inputs

Chapter 7: HTML5 Semantic Elements

7.1 Why Semantic Elements?

Semantic elements clearly describe their meaning to browser and developer. Better for SEO and accessibility.

7.2 New Semantic Tags in HTML5

1. <header>: Introductory content or navigation

2. <nav>: Navigation links section

3. <section>: Thematic grouping of content

4. <article>: Independent, self-contained content

5. <aside>: Sidebar content

6. <footer>: Footer for document or section

7. <main>: Main content of document

8. <figure>: Self-contained content like images with caption

9. <figcaption>: Caption for figure element

<header>
  <h1>Website Title</h1>
  <nav>
  <a href="home.html">Home</a>
  </nav>
</header>
<main>
  <article>
  <h2>Article Title</h2>
  <p>Article content...</p>
  </article>
</main>
<footer>
  <p>Copyright 2026</p>
</footer>

Chapter 8: HTML5 Multimedia

8.1 Audio Tag

<audio> tag embeds sound content.

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

Attributes: controls, autoplay, loop, muted

8.2 Video Tag

<video> tag embeds video content.

<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
  Your browser does not support video.
</video>

Attributes: controls, autoplay, loop, muted, poster

Chapter 9: HTML5 Canvas and SVG

9.1 Canvas

<canvas> element draws graphics via JavaScript.

<canvas id="myCanvas" width="200" height="100"></canvas>
<script>
var c = document.getElementById("myCanvas");
var ctx = c.getContext("2d");
ctx.fillStyle = "#FF0000";
ctx.fillRect(0,0,150,75);
</script>

9.2 SVG

SVG stands for Scalable Vector Graphics. Defines vector-based graphics in XML.

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" stroke="green" stroke-width="4" fill="yellow" />
</svg>

Chapter 10: Best Practices and Tips

10.1 HTML5 Best Practices

1. Always use <!DOCTYPE html>

2. Use lowercase for tag names and attributes

3. Always close tags properly

4. Use alt attribute for images

5. Use semantic elements for better structure

6. Validate your HTML code

7. Keep code indented and readable

8. Use comments <!-- Comment -->

10.2 Common Mistakes to Avoid

1. Missing closing tags

2. Nesting elements incorrectly

3. Using deprecated tags like <font>, <center>

4. Not specifying alt for images

5. Using tables for layout
