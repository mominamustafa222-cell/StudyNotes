Chapter 1: Introduction to Matrices

1.1 Definition of Matrix

A matrix is a rectangular array of numbers, symbols, or expressions arranged in rows and columns. The numbers in a matrix are called elements or entries.

General Form:
A matrix of order m × n is written as:
A = [aij]m×n where i = 1,2,...,m and j = 1,2,...,n

1.2 Types of Matrices

1. Row Matrix: A matrix having only one row. Example: [1 2 3]1×3

2. Column Matrix: A matrix having only one column. Example: [1; 2; 3]3×1

3. Square Matrix: Number of rows = Number of columns. Example: 2×2, 3×3 matrix

4. Diagonal Matrix: A square matrix where all non-diagonal elements are zero.

5. Scalar Matrix: A diagonal matrix where all diagonal elements are equal.

6. Identity Matrix: A scalar matrix with diagonal elements = 1. Denoted by I.

7. Zero Matrix: All elements are zero. Denoted by O.

Example 1: Write a 3×3 identity matrix
Solution: I₃ = [1 0 0]
   [0 1 0]
   [0 0 1]

Chapter 2: Matrix Operations

2.1 Addition of Matrices

Two matrices can be added only if they have the same order. Add corresponding elements.

Formula: If A = [aij] and B = [bij] then
A + B = [aij + bij]
Example 2: Add A = [1 2; 3 4] and B = [5 6; 7 8]
Solution: A + B = [1+5 2+6; 3+7 4+8] = [6 8; 10 12]

2.2 Scalar Multiplication

To multiply a matrix by a scalar k, multiply each element by k.

Formula: kA = [k × aij]

2.3 Matrix Multiplication

Two matrices A and B can be multiplied only if number of columns in A = number of rows in B.

Rule: If A is m×n and B is n×p, then AB is m×p
(AB)ij = Σ aik × bkj for k=1 to n
Example 3: Multiply A = [1 2; 3 4] and B = [2 0; 1 2]
Solution:
AB = [1×2+2×1 1×0+2×2; 3×2+4×1 3×0+4×2]
   = [2+2 0+4; 6+4 0+8] = [4 4; 10 8]

Note: Matrix multiplication is NOT commutative. AB ≠ BA generally.

Chapter 3: Transpose of a Matrix

3.1 Definition

The transpose of a matrix A is obtained by interchanging rows and columns. Denoted by AT or A'

Formula: If A = [aij]m×n then AT = [aji]n×m

3.2 Properties of Transpose

1. (AT)T = A

2. (A + B)T = AT + BT

3. (kA)T = kAT

4. (AB)T = BTAT - Reverse order rule

3.3 Symmetric and Skew-Symmetric Matrices

Symmetric: If AT = A, then A is symmetric matrix.

Skew-Symmetric: If AT = -A, then A is skew-symmetric matrix.

Chapter 4: Determinants

4.1 Determinant of 2×2 Matrix

Formula: If A = [a b; c d] then
|A| = ad - bc
Example 4: Find determinant of A = [3 2; 1 4]
Solution: |A| = (3×4) - (2×1) = 12 - 2 = 10

4.2 Determinant of 3×3 Matrix

Formula: |A| = a11(a22a33 - a23a32) - a12(a21a33 - a23a31) + a13(a21a32 - a22a31)
Example 5: Find |A| where A = [1 2 3; 0 4 5; 1 0 6]
Solution: |A| = 1(4×6 - 5×0) - 2(0×6 - 5×1) + 3(0×0 - 4×1)
   = 1(24-0) - 2(0-5) + 3(0-4)
   = 24 + 10 - 12 = 22

4.3 Properties of Determinants

1. If any two rows or columns are identical, determinant = 0

2. If all elements of a row/column are 0, determinant = 0

3. |AB| = |A| × |B|

4. |AT| = |A|

5. If rows and columns are interchanged, value remains same

6. If any row/column is multiplied by k, determinant becomes k|A|

Chapter 5: Inverse of a Matrix

5.1 Definition

If A is a square matrix and there exists a matrix B such that AB = BA = I, then B is called inverse of A. Denoted by A-1

Condition: A-1 exists only if |A| ≠ 0. Such matrix is called non-singular.

5.2 Inverse of 2×2 Matrix

Formula: If A = [a b; c d] and |A| ≠ 0, then
A-1 = (1/|A|) × [d -b; -c a]
Example 6: Find inverse of A = [4 3; 2 2]
Solution: |A| = 4×2 - 3×2 = 8 - 6 = 2
A-1 = (1/2) × [2 -3; -2 4] = [1 -1.5; -1 2]

5.3 Inverse by Adjoint Method

Formula: A-1 = (1/|A|) × adj(A)
Where adj(A) = Transpose of Cofactor matrix

5.4 Properties of Inverse

1. (A-1)-1 = A

2. (AB)-1 = B-1A-1

3. (AT)-1 = (A-1)T

Chapter 6: Rank of a Matrix

6.1 Definition

The rank of a matrix is the maximum number of linearly independent rows or columns. Denoted by ρ(A).

6.2 Echelon Form Method

Convert matrix to row echelon form. Number of non-zero rows = Rank.

Example 7: Find rank of A = [1 2 3; 2 4 6; 3 6 9]
Solution: R₂ = 2R₁, R₃ = 3R₁. All rows dependent.
Row echelon form: [1 2 3; 0 0 0; 0 0 0]
Only 1 non-zero row. Hence ρ(A) = 1

Chapter 7: System of Linear Equations

7.1 Matrix Method

For system AX = B, if |A| ≠ 0, then X = A-1B

Example 8: Solve: x + 2y = 5, 3x + 4y = 11
Solution: A = [1 2; 3 4], X = [x; y], B = [5; 11]
|A| = 4-6 = -2 ≠ 0
A-1 = (1/-2)[4 -2; -3 1] = [-2 1; 1.5 -0.5]
X = A-1B = [-2×5+1×11; 1.5×5-0.5×11] = [1; 2]
Hence x = 1, y = 2

7.2 Cramer's Rule

xi = |Ai| / |A|
Where Ai is matrix A with i-th column replaced by B

Chapter 8: Eigenvalues and Eigenvectors

8.1 Definition

For a square matrix A, if AX = λX where X ≠ 0, then λ is eigenvalue and X is eigenvector.

Characteristic Equation: |A - λI| = 0
Example 9: Find eigenvalues of A = [2 1; 1 2]
Solution: |A - λI| = |2-λ 1; 1 2-λ| = 0
(2-λ)² - 1 = 0 → λ² - 4λ + 3 = 0
(λ-1)(λ-3) = 0 → λ = 1, 3

8.2 Properties

1. Sum of eigenvalues = Trace of A

2. Product of eigenvalues = |A|

3. If λ is eigenvalue of A, then λk is eigenvalue of Ak

Chapter 9: Cayley-Hamilton Theorem

Every square matrix satisfies its own characteristic equation.

Theorem: If |A - λI| = 0 is characteristic equation, then replacing λ by A, we get zero matrix.
